Tutorial Mode - How to Play SnaQ Math

🎯 Tutorial Objective

This interactive tutorial will teach you every aspect of the math game step by step. Follow the guided instructions to master all game mechanics!

🕹️ Controls You'll Learn

  • WASD or Arrow Keys to move the snake
  • SHIFT to sprint / move faster
  • ESC to pause the game
  • SPACE to resume after pausing
  • R to restart the current game

📚 What You'll Learn

  • Understanding the game interface (Score, Lives, Correct Counter)
  • How to read math questions and find correct answers
  • Snake movement and control
  • Strategic use of sprint feature
  • Pause and resume mechanics
  • Game progression and winning conditions
